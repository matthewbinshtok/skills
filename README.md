# skills

my name is Matthew Binshtok. I work on infrastructure and agents at Vercel.

in March 2026, I wrote an article about the importance of [leveraging AI instead of relying on it](https://vercel.com/blog/agent-responsibly).

as agents become more capable, steering every step doesn't scale. more engineering standards need to be encoded in how they work.

these skills are my attempt to do that: spend less time repeating the same guidance and maintain the quality bar for what I ship, while still understanding the work.

hopefully, these skills can help you do the same.
